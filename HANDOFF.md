headless Chrome); running many concurrent Browser-pane sessions is NOT (they collide).

## 7. Gotchas learned the hard way
- Single "~" is GFM strikethrough; build.js escapes it outside code blocks. Authors use "~" everywhere.
- Inline LaTeX ($...$) is converted by build.js (convertMath); money "$" spans are left alone.
- registerWidget must exist before widget scripts load (index.html defines window.__WIDGETS first).
- HTML entities in TOC/search/key-number rail are decoded in build.js/app.js (was a visible bug).
- The Artifact viewer runs the page in a cross-origin iframe: you cannot script it; test locally.
- Node `String.replace` with a replacement containing `$$` collapses to `$` (broke `$$(` selectors once).
- Spend-limit failures return null from agent(); the pipelines already `.filter(Boolean)`/guard nulls.
- Widget builders may edit site/widget-test.html concurrently (they append their script line); never
  let them touch index.html.
- Memory notes for this project are in the session memory dir (semiconductor-course-project,
  course-v2-iteration, sand-to-gpu-artifact).
